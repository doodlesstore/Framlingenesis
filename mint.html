Mint lewat Agent (metode Boltbook)

Seperti Boltbook, mint di sini dirancang lewat agent, bukan semata tombol di halaman: manusia membaca, agent yang bekerja setelah membaca skill.md. Kirim baris ini ke agent kamu:

Read https://doodlesstore.github.io/Framlingenesis/skill.md and follow the instructions for the Framlin Random collection, then pick a random Framlin and mint it only after my yes.

  1. Agent membaca skill.md koleksi ini.
  2. Agent memeriksa dulu, baru bertindak: alamat kontrak, nomor berikutnya (totalMinted + 1), harga, dan limit — kalau satu pemeriksaan gagal, agent BERHENTI.
  3. Agent menunjukkan preview (nomor, tier, warna, biaya, gas) — tanpa kata ya dari kamu, agent tidak boleh mengeksekusi.
  4. Agent mengeksekusi lewat Binance Agentic Wallet (preview lalu execute), lalu memverifikasi totalMinted dan tokenURI.

Langkah 2–4 di atas adalah metode yang sudah disiapkan di skill.md. Karena kontrak v2 belum ada, langkah itu belum bisa dijalankan hari ini — skill.md dengan jelas menulis begitu, supaya tidak ada agent yang menebak alamat atau harga.

Cara kerja mint acak (nanti)

  1. Mint mengambil nomor berikutnya secara berurutan (totalMinted + 1) — bukan nomor acak yang dipilih di halaman.
  2. Nomor itu sudah punya metadata di repo ini (meta/N.json): tier, hue, saturasi, brightness — jadi warna dan tier token sudah pasti sebelum mint, tidak diundi ulang di kontrak.
  3. Gambar token di wallet/marketplace dibaca dari tokenURI → images/N.jpg di repo ini. Galeri situs menampilkan foto lewat filter browser dari satu master art, tapi wallet tidak memakai filter itu — karena itu upload JPG harus selesai sebelum mint acak dibuka penuh.
  4. Kontrak v2, saat di-deploy, akan diumumkan di repo ini dan di halaman ini — alamat, harga, dan limit dibaca langsung dari kontrak, bukan dikarang di halaman.
