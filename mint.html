MAIN METHOD.

1
AGENT READS SKILL.MD

Send this line to your agent:

Read https://doodlesstore.github.io/Framlingenesis/skill.md and follow the instructions for the Framlin Random collection, then pick a random Framlin and mint it only after my yes.

2
AGENT CHECKS, THEN STOPS IF ANYTHING FAILS

Contract address, next number (totalMinted + 1), price, limit, and that number's metadata — if any single check fails, the agent STOPS and reports.

3
AGENT SHOWS A PREVIEW

Number, tier, colors (from the browser filter), mint cost, and gas — complete, before any transaction.

4
YOU SAY YES — ONLY THEN IT EXECUTES

Without your yes, the agent must not execute. After yes, the agent runs the preview, then executes via the Binance Agentic Wallet, then verifies totalMinted and tokenURI.

HOW RANDOM MINT WORKS

  1. Minting takes the next number in order (totalMinted + 1) — not a random number picked on the page.
  2. That number already has metadata in this repo (meta/N.json): tier, hue, saturation, brightness — so the token's colors and tier are fixed before minting, not re-drawn in the contract.
  3. Token images in wallets/marketplaces are read from tokenURI → images/N.jpg. The gallery uses a browser filter, wallets do not — the JPG upload must finish before mint is fully open.
  4. The contract is live here — address, fee, and limit are read from the contract.
