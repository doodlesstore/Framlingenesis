HOW IT WORKS THESE FILES

  1. Meta: every number has one JSON file in meta/N.json in the Framlingenesis repo — name, description, image link, and attributes (Tier, Hue shift, Saturation, Brightness, Style).
  2. Images: the gallery uses a browser filter on one master art, following the meta attributes (shades may differ slightly from the JPG files). The JPG files in images/N.jpg are still needed as the tokenURI images for wallets/marketplaces.
  3. Random: the gallery order and the Random button use browser randomness. Each number's tier was fixed at generation time (Common 4,017, Uncommon 1,944, Rare 972, Epic 486, Gilded 241, Mythic 117) and stored in the meta — it is not re-drawn on this page.
  4. Mint: the contract is live with its baseURI pointing at this meta; minting takes the next number in order.
