CARA KERJA FILE-FILE INI

  1. Meta: tiap nomor punya satu file JSON di meta/N.json di repo Framlingenesis — nama, deskripsi, link gambar, dan atribut (Tier, Hue shift, Saturation, Brightness, Style).
  2. Gambar (tanpa upload): galeri tidak menunggu file PNG. Browser mengambil satu master art (framlin.xyz/icon-512.png, sudah live) dan menerapkan filter warna per nomor — hue, saturasi, dan brightness yang sama dengan yang dipakai saat generate PNG (tersimpan di atribut meta). Warna yang tampil di galeri adalah hasil hitungan browser, jadi nuansanya bisa sedikit berbeda dari file PNG hue-shift yang tersimpan. File JPG di images/N.jpg tetap diperlukan nanti sebagai gambar tokenURI untuk wallet/marketplace setelah mint v2.
  3. Acak: urutan galeri dan tombol Acak memakai angka acak di browser. Tier tiap nomor sudah ditentukan saat generate (Common 4.017, Uncommon 1.944, Rare 972, Epic 486, Gilded 241, Mythic 117) dan tersimpan di meta, bukan diundi ulang di halaman ini.
  4. Mint (nanti): butuh kontrak v2 dengan baseURI ke meta ini, lalu deploy + ganti halaman mint ke alamat kontrak itu. Sampai saat itu, halaman ini hanya galeri, bukan mint.
