Cara mint (lewat agent, bukan tombol di halaman)

Cara mint di sini meniru Boltbook: bukan tombol mint di halaman, melainkan agent yang mint dari wallet-nya sendiri setelah membaca skill.md. Bedanya dengan Boltbook: tidak ada forum, tidak ada BOLT, tidak ada puzzle runestone — yang di-mint adalah Framlin hue-shift dari koleksi ini, dengan meta yang sudah dibuat sebelumnya.

  1. Agent membaca skill.md koleksi ini.
  2. Agent menentukan nomor berikutnya (totalMinted + 1) dan mengambil meta-nya dari GitHub — nama, tier, hue, saturasi, brightness.
  3. Agent menunjukkan preview ke kamu: nomor, tier, warna (dari filter browser), biaya mint, dan gas. Tanpa kata ya dari kamu, agent tidak boleh mengeksekusi.
  4. Agent menjalankan preview lalu execute lewat Binance Agentic Wallet (BAW), lalu memverifikasi: totalMinted bertambah dan tokenURI nomor itu sesuai meta.

Status mint, terus terang: kontrak v2 untuk koleksi acak ini belum di-deploy — belum ada alamat kontrak, harga, atau limit yang bisa ditulis di sini, dan saya tidak mengarangnya. Jadi langkah 2–4 di atas adalah metode yang sudah disiapkan, bukan mint yang sudah bisa dijalankan hari ini. Mint yang sudah live hari ini adalah koleksi v1 di framlin.xyz (Agent ID only, 1 gratis lalu 0.001 BNB, gambar sama untuk semua token) — itu koleksi berbeda, bukan hue-shift ini.

Galeri Acak

Urutan galeri diacak setiap halaman dibuka. Cari nomor, atau filter berdasarkan tier.

Cara kerja file-file ini

  1. Meta: tiap nomor punya satu file JSON di meta/N.json di repo Framlingenesis — nama, deskripsi, link gambar, dan atribut (Tier, Hue shift, Saturation, Brightness, Style).
  2. Gambar (tanpa upload): galeri tidak menunggu file PNG. Browser mengambil satu master art (framlin.xyz/icon-512.png, sudah live) dan menerapkan filter warna per nomor — hue, saturasi, dan brightness yang sama dengan yang dipakai saat generate PNG (tersimpan di atribut meta). Warna yang tampil di galeri adalah hasil hitungan browser, jadi nuansanya bisa sedikit berbeda dari file PNG hue-shift yang tersimpan. File PNG di images/N.png tetap diperlukan nanti sebagai gambar tokenURI untuk wallet/marketplace setelah mint v2.
  3. Acak: urutan galeri dan tombol Acak memakai angka acak di browser. Tier tiap nomor sudah ditentukan saat generate (Common 4.017, Uncommon 1.944, Rare 972, Epic 486, Gilded 241, Mythic 117) dan tersimpan di meta, bukan diundi ulang di halaman ini.
  4. Mint (nanti): butuh kontrak v2 dengan baseURI ke meta ini, lalu deploy + ganti halaman ini ke alamat kontrak itu. Sampai saat itu, halaman ini hanya galeri, bukan mint.
