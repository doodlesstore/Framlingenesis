Deploy Token Framlin (FRML)

Token reward untuk Framlin Genesis Random. Ini adalah deploy pertama token ini — belum ada token FRML yang beredar sebelum langkah ini.

Spesifikasi yang sudah diputuskan (tidak bisa diubah setelah deploy):

  • Nama: Framlin · Simbol: FRML · Desimal: 18
  • 1.000 FRML per 1 mint NFT, rata untuk semua tier
  • Maksimal: 7.777.000 FRML (7.777 NFT × 1.000) — tercapai hanya lewat mint NFT
  • Token hanya bisa dibuat oleh minter (kontrak NFT, setelah dihubungkan). Owner tidak bisa mencetak token langsung.
  • Tanpa pajak transfer, tanpa burn, tanpa blacklist.

Peringatan: kontrak ini belum diaudit. Coba dengan jumlah kecil dulu. Deploy hanya dari wallet kamu sendiri di dApp browser (OKX / MetaMask / Trust). Jangan pernah kirim seed phrase atau private key ke siapa pun.
