Deploy Token Framlin (FRML)

Token reward for Framlin Genesis Random. This is this token's first deployment — no FRML tokens were in circulation before this step.

Specifications already decided (cannot be changed after deployment):

  • Nama: Framlin · Simbol: FRML · Desimal: 18
  • 1,000 FRML per 1 NFT mint, flat for all tiers
  • Max: 7,777,000 FRML (7,777 NFTs × 1,000) — reached only via NFT minting
  • Tokens can only be created by the minter (the NFT contract, once connected). The owner cannot mint tokens directly.
  • Tanpa pajak transfer, tanpa burn, tanpa blacklist.

Warning: this contract is unaudited. Try small amounts first. Deploy only from your own wallet in a dApp browser (OKX / MetaMask / Trust). Never send a seed phrase or private key to anyone.
