Deploy NFT Framlin Genesis Random (FRAMR)

This is this collection's first deployment — there was no NFT contract for this collection before this step.

Rules already decided (locked in the contract after deployment):

  • Nama: Framlin Genesis Random · Simbol: FRAMR · Supply: 7,777
  • Token free; creator fee per mint: 0.0001 BNB for mints 1–600, 0.0002 BNB for 601–7,777 — the fee is forwarded straight to the creator (owner) on every mint, not held in the contract
  • Limit: 10 per wallet
  • Agent ID only: only wallets holding a Binance Agent ID can mint; personal wallets only (not smart contracts)
  • Every mint also gives 1,000 FRML to the minter (via the token contract — the token must be connected first, see step 3)
  • tokenURI = baseURI + number + .json (meta files are N.json)
  • Mint is CLOSED by default — the owner opens it in step 4, only after the token is connected

Warning: this contract is unaudited. Try small amounts first. Deploy only from your own wallet in a dApp browser (OKX / MetaMask / Trust). Never send a seed phrase or private key to anyone.
